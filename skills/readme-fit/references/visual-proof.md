# Visual proof rubric

Evaluate proof, not visual beauty.

Possible proof includes screenshots, GIFs, terminal output, recordings, video links, before/after examples, architecture diagrams, and interactive demos.

For each detected item, ask:

1. Does it show the core value or only branding?
2. Is it representative of the current project?
3. Does it reveal the result a user should expect?
4. Is it placed before the visitor must understand too much abstract context?
5. Is this proof form appropriate for the project type?

Terminal output can be sufficient for a CLI. A small library can be well documented without a video. A desktop app usually needs a visible product state. An architecture diagram proves structure, not necessarily user value.

Recommend before/after only for projects whose value is a transformation and only when the contrast makes the outcome easier to understand.
